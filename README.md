# Rešitve maturitetne pole iz matematike v Wolfram Mathematica
Ta repozitorij vsebuje **rešene naloge 2. pole osnovne ravni spomladanskega roka 2023** iz mature iz matematike, pripravljene v okolju Wolfram Mathematica. Cilj je omogočiti jasne in razumljive rešitve. Rešitve so bile spisane na roko, zato se lahko pojavi kakšna vsebinska napaka. Sicer pa so bile preverjene z uradnimi rešitvami in se z njimi skladajo.

Skratka, tukaj si lahko ogledaš [2. polo spomladanskega roka 2023](https://www.ric.si/mma/M231-401-1-2.pdf/20231009130328/?m=1696849408), tukaj pa so [moje rešitve](https://meglicka.github.io/Matura-pomlad-2023-OR-pola-2/). Srečno pri učenju!
